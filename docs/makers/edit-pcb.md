# Edit the PCB

The board isn't hand-drawn. It's **generated by a Python script** with KiCad's scripting API, then autorouted with [freerouting](https://github.com/freerouting/freerouting). Change the script, rerun, and get fresh order files.

Files are in [`hardware/pcb/source/`](https://github.com/JamesSilvia20/xiao-garage-door/tree/main/hardware/pcb/source):

| File | What it does |
|---|---|
| `build_board.py` | Places every part, assigns nets, draws the outline and silkscreen |
| `route.py` | Exports to freerouting and imports the result, then adds the GND pours |
| `make.sh` | Runs everything: build → autoroute → pour → KiCad DRC |
| `export_jlc.py` | Writes the JLCPCB BOM and CPL with LCSC part numbers |
| `garage_door.kicad_pcb` | The finished board; open it in KiCad to look around |

## Requirements

- **KiCad 10.** On macOS the scripts expect it in `~/Applications/KiCad`; change the paths at the top of `make.sh` and `build_board.py` for other locations.
- **Java 25+** (for freerouting 2.x). On macOS: `brew install openjdk`.
- **freerouting.jar**, downloaded to `~/.cache/freerouting/freerouting.jar` from the [releases page](https://github.com/freerouting/freerouting/releases).

## Rebuild

```bash
cd hardware/pcb/source
./make.sh                       # build, route, pour, DRC -> drc.json
"$KICAD_PY" export_jlc.py        # BOM + CPL
kicad-cli pcb export gerbers --no-protel-ext -l F.Cu,B.Cu,F.Paste,B.Paste,F.Silkscreen,B.Silkscreen,F.Mask,B.Mask,Edge.Cuts -o gerbers/ garage_door.kicad_pcb
kicad-cli pcb export drill --format excellon --excellon-separate-th -o gerbers/ garage_door.kicad_pcb
```

Here `$KICAD_PY` is KiCad's bundled Python, for example `~/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3` on macOS.

The last run had **0 unconnected items and 0 electrical errors**. The only warnings are the screw-terminal outlines touching the board edge, which is intended because they sit flush.
